# SmokeTrail 💨

> A SmokePing-inspired network monitoring and visualization tool for Windows environments.

SmokeTrail delivers long-term network quality tracking—monitoring latency variations, jitter, and packet loss over time with intuitive visual charts. Built specifically for Windows, it provides a straightforward setup and a native running experience.

---

### Key Features

* 📊 **Latency & Loss Visualization**: Displays historical ping trends and packet loss density using clear, Smokeping-style chart visualizations.
* 💻 **Windows-Native Design**: Optimized specifically for Windows systems, ensuring smooth integration without requiring additional cross-platform runtimes.
* 🛠️ **Simple Configuration & Setup**: Straightforward setup process allowing you to start monitoring targets in minutes.
* 📈 **Multi-Target Tracking**: Continuously monitors multiple IP addresses, domains, or gateways simultaneously.
* ⚡ **Resource Efficient**: Designed for continuous background operation with minimal CPU and memory usage.

---

### Common Use Cases

* **Network Operations**: Monitor latency trends across Windows servers, local gateways, and ISP connections.
* **Troubleshooting**: Diagnose home network instability, VPN connection drops, or gaming lag over custom time ranges.
* **ISP Comparison**: Compare route stability across different targets over a 24-hour period.
